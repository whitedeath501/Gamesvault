# GameVault

Projeto autoral de uma plataforma de catálogo, avaliações e recomendações de jogos, desenvolvido com HTML, CSS e JavaScript puro.

## Funcionalidades
- Catálogo com 12 jogos de exemplo.
- Busca por nome ou gênero.
- Filtro por gênero e ordenação.
- Favoritos salvos no `localStorage`.
- Recomendações aleatórias.
- Página de detalhes em janela modal.
- Avaliação pessoal de 1 a 5 estrelas, salva no navegador.
- Layout responsivo para desktop e celular.

## Como executar
Abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.

## Publicar no GitHub Pages
1. Crie um repositório público chamado `gamevault` no GitHub.
2. Envie `index.html`, a pasta `css`, a pasta `js` e este `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço será parecido com `https://SEU-USUARIO.github.io/gamevault/`.

## Observação
As capas usam imagens externas do Unsplash. É necessário estar conectado à internet para carregá-las. Os jogos e notas do catálogo são dados demonstrativos; as avaliações pessoais e favoritos ficam armazenados apenas no navegador utilizado.
